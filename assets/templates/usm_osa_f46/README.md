# USM-OSA-F46 Template Reference

Store the official visual reference for the liquidation report in this folder.

Preferred filenames:

- `usm_osa_f46_reference.pdf`
- `usm_osa_f46_page1.png`

Audivance does not depend on runtime PDF rendering for report generation. The reference files are for local visual QA and alignment checks while maintaining the template-driven PDF layout in Dart.
